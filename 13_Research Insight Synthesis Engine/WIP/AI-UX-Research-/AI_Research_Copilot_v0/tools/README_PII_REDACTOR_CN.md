# 离线个人信息脱敏工具（POC）

此工具只使用 Python 标准库，在本机读取和写入文件，不调用模型、网络 API 或任何外部服务。
原文件不会被覆盖，默认在同目录生成 `*.redacted.*`。

## 网页版（选择文件 → 下载）

双击项目中的 `START_MAC.command`，打开 Research Agent 后点击右上角“先脱敏文件”；也可以直接访问：

```text
http://127.0.0.1:8000/redactor.html
```

网页会在浏览器内存中读取、识别、脱敏和生成下载文件，不把文件内容提交给本地后端或外部服务。流程分为“识别候选 → 人工勾选或删除误识别项 → 确认脱敏 → 下载”，确认前不会修改文件。网页版额外支持 `.docx`，脱敏后下载为保留 Word 结构的 `.redacted.docx`。

## 使用

进入 `AI_Research_Copilot_v0` 目录后运行：

```bash
python3 tools/pii_redactor.py "访谈记录.txt"
```

处理整个目录，并把结果集中写到一个本地目录：

```bash
python3 tools/pii_redactor.py "待脱敏访谈/" -o "已脱敏访谈/" --report "已脱敏访谈/report.json"
```

补充规则无法可靠推断的姓名、公司或项目名：

```bash
python3 tools/pii_redactor.py "访谈记录.md" \
  --name "张三" \
  --name "李小明" \
  --term "公司=示例科技有限公司" \
  --term "项目=北极星项目"
```

命令行版支持 UTF-8 编码的 `.txt`、`.md`、`.csv`、`.json`、`.srt`、`.vtt`；网页版另外支持 `.docx`。同一批次中相同原值会得到相同占位符，例如 `[手机号_001]`，方便保留跨材料关联；报告只记录类型、数量和输出路径，不记录敏感原值。

## 默认识别范围

- 邮箱、手机号、座机；
- 中国居民身份证、常见护照号、银行卡号；
- 中国车牌、IPv4、带标签的 QQ 号和微信号；
- 带“姓名 / 联系人 / 受访者 / 参与者”等标签的中文姓名；
- “我叫张三 / 名字是李小明”等常见自我介绍，以及“王芳：……”形式的说话人姓名；
- 带“住址 / 居住地址 / 通讯地址 / 地址”标签的单行地址。

## 重要限制

这是确定性规则 POC，不是完整的自然语言实体识别系统。无标签姓名、口语化地址、昵称、罕见证件号可能漏检；普通长数字也可能误判。Word 可能把一段文字拆成多个格式片段，刚好跨片段的个人信息也可能漏检。把材料交给 Research Agent 或任何获批服务前，必须人工复核脱敏结果。建议通过已知姓名和自定义词条补充本项目敏感信息。

不要把待脱敏原件放进 OneDrive 同步目录。如果原件已在同步目录，应先按团队数据治理要求处理同步副本和历史版本。
