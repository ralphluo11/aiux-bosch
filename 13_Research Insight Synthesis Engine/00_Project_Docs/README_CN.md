# 00_Project_Docs — 目录说明

项目文档放在**项目主文件夹**下（与 `WIP/` 平级），按类别分子文件夹。

| 文件夹 | 内容 |
|--------|------|
| **00_Strategy/** | 平台战略上下文、Research Agent 当前状态与战略缺口；内容为方向和审计基线，不替代正式批准 |
| **01_PRD/** | 立项 PRD（`PRD.md`、`PRD_CN.md`、`PRD_bilingual.html`）+ 执行 PRD（`EXECUTION_PRD.md`、`EXECUTION_PRD_CN.md`）+ 追问评测专项（`PROBE_EVAL_BOOTSTRAP_PRD_CN.md`） |
| **02_RETRO/** | 复盘（`RETRO.md`、`RETRO_CN.md`、`RETRO_bilingual.html`） |
| **03_Content_Gaps/** | 缺失内容提醒（`CONTENT_GAPS_CN.md`、`CONTENT_GAPS.csv`） |
| **04_Weekly_Plans/** | 按当前日期制定的阶段执行计划、投入上限、验证 Gate 与继续/停止决策 |

**浏览器查看：** 打开各文件夹里的 `*_bilingual.html` 即可。

**说明：** UX 研究规划产出在 `WIP/Research/`，勿写入本目录。
